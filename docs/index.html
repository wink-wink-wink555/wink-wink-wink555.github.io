Battery Cycle-Life Prediction and Streaming Analytics (Oct 2025 – May 2026)

  • Built a battery cycle-life prediction pipeline using approximately 100K cycle-level records from 124 cells; compared ElasticNet, Random Forest, and XGBoost using cell-level train/test splits, with XGBoost reaching R² 0.89 on held-out cells.
  • Turned the batch workflow into a streaming prototype by replaying 12M+ battery telemetry events through Kafka and Spark Structured Streaming into HDFS, with checkpointing and deduplication.
  • Processed out-of-order sensor data in Flink with event-time watermarks and tumbling windows, and ran the offline model in PyFlink using exported preprocessing and model parameters.
